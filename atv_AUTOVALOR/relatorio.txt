RELATÓRIO - AUTOVALOR E AUTOVETOR COM MPI
=========================================


1. O QUE É AUTOVALOR E AUTOVETOR
--------------------------------

Quando a gente multiplica uma matriz A por um vetor v, normalmente o vetor
muda de direção. Mas existem alguns vetores especiais que não mudam de
direção, só ficam maiores ou menores:

    A · v = λ · v

- v é o AUTOVETOR (o vetor que não muda de direção)
- λ é o AUTOVALOR (quanto o vetor foi esticado)

A atividade pede o MAIOR autovalor da matriz e o autovetor dele.


2. COMO A MATRIZ A FOI DEFINIDA
-------------------------------

Tamanho: n x n. Rodei com n = 8 e com n = 1000.

Conteúdo: 2 na diagonal e 1 em todo o resto. Exemplo com n = 3:

    | 2  1  1 |
    | 1  2  1 |
    | 1  1  2 |

Escolhi essa matriz porque dá pra saber a resposta certa na mão, pra
qualquer tamanho n:

    maior autovalor = n + 1
    autovetor       = todos os números iguais: (1, 1, ..., 1)

Por quê? Multiplicando a matriz pelo vetor (1, 1, ..., 1), cada linha soma
um 2 e (n - 1) números 1, o que dá n + 1. Então:

    A · (1, 1, ..., 1) = (n+1, n+1, ..., n+1) = (n + 1) · (1, 1, ..., 1)

No código o autovetor sai "normalizado" (com tamanho 1), então cada número
dele fica 1 / raiz(n).

    n = 8    -> autovalor certo = 9    e autovetor certo = 0,353553 em tudo
    n = 1000 -> autovalor certo = 1001 e autovetor certo = 0,031623 em tudo

Quem define a matriz é só o processo 0, como a atividade pede.


3. RESOLVENDO NA MÃO (n = 2)
----------------------------

    A = | 2  1 |
        | 1  2 |

Passo 1 - Achar os autovalores.
A conta é: det(A - λI) = 0

    | 2-λ   1  |
    |  1   2-λ |  ->  (2 - λ)² - 1 = 0

    (2 - λ)² = 1
    2 - λ = 1   ou   2 - λ = -1
    λ = 1       ou   λ = 3

Autovalores: 3 e 1. O maior é 3 (que é n + 1 = 2 + 1).

Passo 2 - Achar o autovetor do λ = 3.
A conta é: (A - 3I) · v = 0

    | -1   1 | | v1 |   | 0 |
    |  1  -1 | | v2 | = | 0 |   ->   -v1 + v2 = 0   ->   v1 = v2

Autovetor: (1, 1). Conferindo: A · (1, 1) = (2+1, 1+2) = (3, 3) = 3 · (1, 1).

Normalizado (tamanho 1): (1/raiz(2), 1/raiz(2)) = (0,7071; 0,7071)


4. O MÉTODO DO SLIDE (MÉTODO DA POTÊNCIA)
-----------------------------------------

Pra matrizes grandes não dá pra fazer a conta do determinante. Então o
computador repete estes passos:

    1. Multiplica: y = A · x
    2. Estima o autovalor: λ = (xᵀ · A · x) / (xᵀ · x)
    3. Normaliza: x novo = y / tamanho de y
    4. Repete até o λ parar de mudar.

Cada vez que multiplica pela matriz, o vetor vai "virando" na direção do
autovetor do maior autovalor.

Exemplo na mão com n = 2, começando com x = (1, 2) normalizado:

    volta   x                  y = A · x          λ        x novo
    -----   ----------------   ----------------   ------   ----------------
    1       (0,4472; 0,8944)   (1,7889; 2,2361)   2,8000   (0,6247; 0,7809)
    2       (0,6247; 0,7809)   (2,0303; 2,1864)   2,9756   (0,6805; 0,7328)
    3       (0,6805; 0,7328)   (2,0937; 2,1460)   2,9973   (0,6983; 0,7158)
    4       (0,6983; 0,7158)   (2,1124; 2,1299)   2,9997   (0,7042; 0,7100)

O λ vai chegando em 3 (o autovalor) e o x vai chegando em (0,7071; 0,7071)
(o autovetor). Igualzinho à conta do item 3.


5. COMO O MPI DIVIDE O TRABALHO
-------------------------------

Passo 1 - O processo 0 cria a matriz inteira.

Passo 2 - MPI_Scatter: o processo 0 divide as linhas entre todos. Com
n = 8 e 8 processos, cada um fica com 1 linha. Com n = 1000, cada um fica
com 125 linhas. Depois disso o processo 0 apaga a matriz inteira (free), e
cada processo só tem as suas linhas. Nenhum processo vê as linhas dos outros.

Passo 3 - Em cada volta do método:

    - Cada processo multiplica as suas linhas por x e calcula o seu pedaço
      de y.
    - MPI_Allreduce: soma os pedaços de xᵀ·A·x de todo mundo, pra calcular
      o λ.
    - MPI_Allreduce: soma os pedaços do tamanho de y, pra normalizar.
    - Cada processo normaliza o seu pedaço de y, que vira o seu pedaço do
      x novo.
    - MPI_Allgather: junta os pedaços do x novo e entrega o x completo pra
      TODOS os processos. Todo mundo precisa do x inteiro pra próxima volta,
      porque cada linha da matriz é multiplicada pelo x inteiro.

O número de linhas (n) precisa ser divisível pelo número de processos, pra
cada um ficar com a mesma quantidade. Se não for, o programa avisa e para.


6. O CÓDIGO (autovalor_mpi.c)
-----------------------------

#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <mpi.h>

int main(int argc, char* argv[]){
    int comm_sz;
    int my_rank;

    int n = 8;
    if(argc > 1) n = atoi(argv[1]);
    int max_iter = 1000;
    double tolerancia = 1e-12;

    MPI_Init(&argc, &argv);
    MPI_Comm_size(MPI_COMM_WORLD, &comm_sz);
    MPI_Comm_rank(MPI_COMM_WORLD, &my_rank);

    if(n % comm_sz != 0){
        if(my_rank == 0) printf("Erro: n = %d precisa ser divisivel por p = %d\n", n, comm_sz);
        MPI_Finalize();
        return 1;
    }

    int linhas = n / comm_sz;

    double *A = NULL;
    if(my_rank == 0){
        A = malloc((long)n * n * sizeof(double));
        for(int i=0; i<n; i++){
            for(int j=0; j<n; j++){
                if(i == j) A[(long)i*n + j] = 2.0;
                else A[(long)i*n + j] = 1.0;
            }
        }
    }

    double *A_local = malloc((long)linhas * n * sizeof(double));
    MPI_Scatter(A, linhas * n, MPI_DOUBLE, A_local, linhas * n, MPI_DOUBLE, 0, MPI_COMM_WORLD);

    if(my_rank == 0){
        free(A);
        A = NULL;
    }

    double *x = malloc(n * sizeof(double));
    double *y_local = malloc(linhas * sizeof(double));
    double *x_local = malloc(linhas * sizeof(double));

    double norma = 0.0;
    for(int i=0; i<n; i++){
        x[i] = i + 1;
        norma += x[i] * x[i];
    }
    norma = sqrt(norma);
    for(int i=0; i<n; i++){
        x[i] = x[i] / norma;
    }

    int inicio = my_rank * linhas;
    double lambda = 0.0;
    double lambda_antigo = 0.0;
    int iter;

    for(iter=1; iter<=max_iter; iter++){
        for(int i=0; i<linhas; i++){
            double soma = 0.0;
            for(int j=0; j<n; j++){
                soma += A_local[(long)i*n + j] * x[j];
            }
            y_local[i] = soma;
        }

        double xAx_local = 0.0;
        for(int i=0; i<linhas; i++){
            xAx_local += x[inicio + i] * y_local[i];
        }
        double xAx;
        MPI_Allreduce(&xAx_local, &xAx, 1, MPI_DOUBLE, MPI_SUM, MPI_COMM_WORLD);

        double xx = 0.0;
        for(int i=0; i<n; i++){
            xx += x[i] * x[i];
        }

        lambda = xAx / xx;

        double norma_local = 0.0;
        for(int i=0; i<linhas; i++){
            norma_local += y_local[i] * y_local[i];
        }
        MPI_Allreduce(&norma_local, &norma, 1, MPI_DOUBLE, MPI_SUM, MPI_COMM_WORLD);
        norma = sqrt(norma);

        for(int i=0; i<linhas; i++){
            x_local[i] = y_local[i] / norma;
        }
        MPI_Allgather(x_local, linhas, MPI_DOUBLE, x, linhas, MPI_DOUBLE, MPI_COMM_WORLD);

        if(fabs(lambda - lambda_antigo) < tolerancia * fabs(lambda)) break;
        lambda_antigo = lambda;
    }

    if(my_rank == 0){
        double exato = n + 1;
        double v_exato = 1.0 / sqrt(n);
        double erro_vetor = 0.0;
        for(int i=0; i<n; i++){
            double e = fabs(x[i] - v_exato);
            if(e > erro_vetor) erro_vetor = e;
        }

        printf("Tamanho da matriz: %d x %d\n", n, n);
        printf("Processos: %d (%d linhas para cada)\n", comm_sz, linhas);
        printf("Iteracoes: %d\n", iter);
        printf("Autovalor calculado: %.10f\n", lambda);
        printf("Autovalor exato:     %.10f\n", exato);
        printf("Erro do autovalor:   %.3e\n", fabs(lambda - exato));
        printf("Erro do autovetor:   %.3e\n", erro_vetor);
        if(n <= 10){
            printf("Autovetor: (");
            for(int i=0; i<n; i++){
                printf("%.6f", x[i]);
                if(i < n-1) printf(", ");
            }
            printf(")\n");
        } else {
            printf("Autovetor (primeiros 5): (%.6f, %.6f, %.6f, %.6f, %.6f, ...)\n",
                   x[0], x[1], x[2], x[3], x[4]);
        }
        printf("Valor certo de cada posicao do autovetor: 1/raiz(%d) = %.6f\n", n, v_exato);
        printf("\n");
    }

    free(A_local);
    free(x);
    free(y_local);
    free(x_local);
    MPI_Finalize();
    return 0;
}

O que cada parte faz:

- n: tamanho da matriz (vem da linha de comando).
- max_iter e tolerancia: o programa para quando o λ para de mudar ou depois
  de 1000 voltas.
- linhas: quantas linhas cada processo recebe (n / número de processos).
- A: a matriz inteira. Só existe no processo 0, e é apagada depois do
  MPI_Scatter.
- A_local: as linhas da matriz que este processo recebeu.
- x: o vetor completo, que todo processo tem.
- y_local: o pedaço de y = A · x que este processo calculou.
- x_local: o pedaço do x novo (y_local normalizado).
- xAx e xx: as duas partes da fórmula do λ.
- norma: o tamanho de y, usado pra normalizar.
- inicio: em qual posição do x começam as linhas deste processo.
- No final, o processo 0 compara com os valores certos e mostra o resultado.


7. COMO RODAR NO NPAD
---------------------

Script de submissão (job_autovalor.sh):

#!/bin/bash
#SBATCH --job-name=autovalor
#SBATCH --output=resultados_autovalor.txt
#SBATCH --partition=amd-512
#SBATCH --nodes=2
#SBATCH --ntasks-per-node=4
#SBATCH --time=0-0:5

echo "Nos alocados: $SLURM_JOB_NODELIST"
echo ""

mpirun ./autovalor_mpi 8
mpirun ./autovalor_mpi 1000

Ele pede 2 nós com 4 processos em cada nó (8 processos no total) e roda o
programa com a matriz 8 x 8 e com a matriz 1000 x 1000.

Comandos:

    mpicc autovalor_mpi.c -o autovalor_mpi -lm
    sbatch job_autovalor.sh
    cat resultados_autovalor.txt

9. CONCLUSÃO
------------

- O autovalor encontrado foi 9 pra matriz 8 x 8 e 1001 pra matriz
  1000 x 1000, que são exatamente os valores certos (n + 1).

- O autovetor também bateu: todos os números iguais a 1/raiz(n).

- O erro ficou muito pequeno, só arredondamento do computador.

- O método precisou de poucas voltas. Isso acontece porque nessa matriz o
  maior autovalor (n + 1) é muito maior que os outros (que valem 1), então
  o vetor vira rápido na direção certa.

- Cada processo só trabalhou com as suas linhas da matriz, e o MPI_Allgather
  garantiu que todos tivessem o x completo a cada volta.
